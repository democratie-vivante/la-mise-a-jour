# Citoyen 2.0 — Hub `plan-democratie.fr` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer le site web hub satirique « Citoyen 2.0 » (page unique, expérience SaaS complète) servant de source officielle à toute la diffusion.

**Architecture:** Page HTML unique (`index.html`) + feuille de style (`styles.css`) + JS sans dépendance (`main.js`), testés par `unittest` Python (structure, contenu, contraste, contraintes CSS) et vérifiés en navigateur réel via les outils `browser.evaluate`. Aucun build, aucun `package.json`.

**Tech Stack:** HTML5 sémantique, CSS moderne (custom properties, grid, media queries), JS vanilla (IIFE, `defer`), Python 3.12 `unittest` (stdlib uniquement), `python3 -m http.server` pour la vérification navigateur.

**Spec:** `docs/superpowers/specs/2026-09-23-citoyen-2-0-design.md` — le plan argumente depuis la spec ; l'exécutant lit les deux.

## Global Constraints

- **Zéro dépendance :** aucun `package.json`, aucun build, aucun CDN. Scripts et feuilles de style référencés en chemins relatifs uniquement.
- **Langue :** `<html lang="fr">`, 100 % de la copie en français (titres, boutons, textes alternatifs, messages).
- **Identité :** produit « Citoyen 2.0 », URL canonique `https://plan-democratie.fr/` (sans `www`).
- **Aucune mention du calculateur** : le mot « calculateur » n'apparaît ni dans `index.html`, ni dans `styles.css`, ni dans `main.js` (spec §10).
- **Comptes figés :** 8 lignes de features par carte de prix (16 `<li class="plan-row">` au total), exactement 6 cartes `feature-card`, exactement 6 éléments `<details class="faq-item">`.
- **Pricing table capturable en HD :** section `#tarifs` sur fond blanc uni, largeur max 1080 px, **aucune animation ni transition** dans les règles CSS de `.pricing` (spec §4).
- **Ordre mobile :** dans `@media (max-width: 768px)`, `.plan--popular` reçoit `order: -1` (la 6ᵉ d'abord).
- **Partages toujours sur l'URL canonique :** les URLs générées contiennent `https://plan-democratie.fr/` et jamais l'origine de service (`localhost`).
- **Accessibilité :** contrastes ≥ 4,5:1 (testés), `:focus-visible` présent, boutons `ⓘ` en `<button>` avec `aria-expanded` + `aria-controls`, FAQ au clavier.
- **Tests :** `python3 -m unittest discover -s tests -v` (depuis la racine) doit passer à chaque fin de tâche. Aucun autre outil de test.

## Review Focus

1. **URLs de partage servies depuis `localhost`** — un utilisateur testant localement partagerait `http://localhost:8765/` ; attendu : les boutons partagent toujours `https://plan-democratie.fr/`. → Test navigateur (Task 8) : `buildShareUrl` contient `plan-democratie.fr` et pas `localhost`.
2. **Infobulle non fermable** — ouverte par clic, elle resterait affichée devant le contenu ; attendu : fermeture par `Échap`, par clic extérieur, et une seule ouverte à la fois. → Tests navigateurs (Task 6) : `keydown Escape` puis clic sur `body` ramènent `aria-expanded="false"`.
3. **FAQ cumulant plusieurs réponses ouvertes** — attendu : une seule question ouverte à la fois, ouverture/fermeture synchrones au clic sur `<summary>`. → Test navigateur (Task 7) : ouvrir la 1ʳᵉ puis la 2ᵉ ⇒ `(false, true)`.
4. **`navigator.clipboard` indisponible** (contexte non sécurisé / refus de permission) — le clic sur « Copier le lien » lèverait une erreur et n'afficherait aucun retour ; attendu : aucun throw, feedback affiché quand même. → Test navigateur (Task 8) : override `navigator.clipboard = undefined`, clic, `#copy-feedback.hidden === false`.
5. **Régression de capture HD et débordement mobile** — une animation glissée dans la pricing table ou un élément débordant casserait l'image virale ; attendu : zéro `animation`/`transition` dans `.pricing`, aucun élément au-delà de la largeur de fenêtre. → Tests : extraction des blocs CSS `.pricing*` (Task 4), test de débordement navigateur (Task 9).

import html as html_mod
import re
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
INDEX = (ROOT / "index.html").read_text(encoding="utf-8")
CSS = (ROOT / "styles.css").read_text(encoding="utf-8")
JS = (ROOT / "main.js").read_text(encoding="utf-8")


def text():
    """Texte visible de la page, entités et espaces insécables normalisés."""
    body = INDEX.split("<body", 1)[1].split(">", 1)[1]
    body = html_mod.unescape(body).replace("\xa0", " ")
    return re.sub(r"\s+", " ", re.sub(r"<[^>]+>", " ", body))


def css_rules(selector_prefix):
    """Concatène les corps de règles dont le sélecteur commence par le préfixe."""
    pattern = re.compile(
        r"([^{}]*" + re.escape(selector_prefix) + r"[^{}]*)\{([^{}]*)\}"
    )
    return " ".join(m.group(2) for m in pattern.finditer(CSS))


class SiteStructureTests(unittest.TestCase):
    def test_lang_is_french(self):
        self.assertIn('<html lang="fr">', INDEX)

    def test_share_meta_are_absolute_https(self):

```python
def media_blocks():
    """Liste (condition, corps) de chaque bloc @media, accolades équilibrées."""
    blocks = []
    for m in re.finditer(r"@media([^{]+)\{", CSS):
        depth, i, start = 1, m.end(), m.end()
        while depth:
            if CSS[i] == "{":
                depth += 1
            elif CSS[i] == "}":
                depth -= 1
            i += 1
        blocks.append((m.group(1).strip(), CSS[start:i - 1]))
    return blocks


class PricingTests(unittest.TestCase):
    def test_section_and_cards(self):
        self.assertRegex(INDEX, r'<section id="tarifs" class="section pricing"[^>]*>')
        self.assertEqual(INDEX.count('class="plan plan--legacy"'), 1)
        self.assertEqual(INDEX.count('class="plan plan--popular"'), 1)
        self.assertIn("POPULAIRE", text())

    def test_eight_rows_per_card_sixteen_total(self):

(function () {
  "use strict";

  function closeAllTooltips(except) {
    document.querySelectorAll('.info-btn[aria-expanded="true"]').forEach(function (btn) {
      if (btn === except) return;
      btn.setAttribute("aria-expanded", "false");
      var tip = document.getElementById(btn.getAttribute("aria-controls"));
      if (tip) tip.hidden = true;
    });
  }

  function toggleTooltip(btn) {
    var isOpen = btn.getAttribute("aria-expanded") === "true";
    closeAllTooltips(isOpen ? null : btn);
    btn.setAttribute("aria-expanded", isOpen ? "false" : "true");
    var tip = document.getElementById(btn.getAttribute("aria-controls"));
    if (!tip) return;
    tip.hidden = isOpen;
    if (isOpen) return;
    tip.classList.remove("tooltip--below");
    if (tip.getBoundingClientRect().top < 8) {
      tip.classList.add("tooltip--below");
    }
  }

  function initTooltips() {
    document.querySelectorAll(".info-btn").forEach(function (btn) {
      btn.addEventListener("click", function (event) {
        event.stopPropagation();
        toggleTooltip(btn);
      });
    });
    document.addEventListener("click", function (event) {
      if (!event.target.closest(".tip-wrap")) closeAllTooltips(null);
    });
    document.addEventListener("keydown", function (event) {
      if (event.key === "Escape") closeAllTooltips(null);
    });
  }

  initTooltips();
})();
```

  var CANONICAL_URL = "https://plan-democratie.fr/";
  var SHARE_TEXT = "Quel est votre plan de citoyenneté ? Découvrez le Plan 6ᵉ République.";

  function buildShareUrl(platform, pageUrl) {
    var url = pageUrl || CANONICAL_URL;
    if (platform === "whatsapp") {
      return "https://wa.me/?text=" + encodeURIComponent(SHARE_TEXT + " " + url);
    }
    if (platform === "x") {
      return "https://twitter.com/intent/tweet?text=" + encodeURIComponent(SHARE_TEXT) +
        "&url=" + encodeURIComponent(url);
    }
    if (platform === "facebook") {
      return "https://www.facebook.com/sharer/sharer.php?u=" + encodeURIComponent(url);
    }
    return null;
  }
  window.buildShareUrl = buildShareUrl;

  function showFeedback(message) {
    var el = document.getElementById("copy-feedback");
    if (!el) return;
    el.textContent = message;
    el.hidden = false;
    window.clearTimeout(showFeedback._timer);
    showFeedback._timer = window.setTimeout(function () {
      el.hidden = true;
    }, 2500);
  }

  function legacyCopy(text) {
    var ta = document.createElement("textarea");
    ta.value = text;
    ta.setAttribute("readonly", "");
    ta.style.position = "fixed";
    ta.style.opacity = "0";
    document.body.appendChild(ta);
    ta.select();
    try {
      return document.execCommand("copy");
    } catch (err) {
      return false;
    } finally {
      ta.remove();
    }
  }

  function copyText(text) {
    if (navigator.clipboard && navigator.clipboard.writeText) {
      return navigator.clipboard.writeText(text).then(function () {
        return true;
      }, function () {
        return legacyCopy(text);
      });
    }
    return Promise.resolve(legacyCopy(text));
  }

  function initShare() {
    document.querySelectorAll("[data-platform]").forEach(function (el) {
      var platform = el.getAttribute("data-platform");
      if (platform === "signal") {
        el.addEventListener("click", function () {
          var payload = { title: "Citoyen 2.0", text: SHARE_TEXT, url: CANONICAL_URL };
          if (navigator.share) {
            navigator.share(payload).catch(function () {});
          } else {
            copyText(SHARE_TEXT + " " + CANONICAL_URL).then(function () {
              showFeedback("Lien copié — collez-le dans Signal");
            });
          }
        });
        return;
      }
      var href = buildShareUrl(platform, CANONICAL_URL);
      if (href && el.tagName === "A") el.href = href;
    });
  }

  function initCopy() {
    var btn = document.getElementById("copy-link");
    if (!btn) return;
    btn.addEventListener("click", function () {
      showFeedback("✓ Lien copié");
      copyText(CANONICAL_URL).then(function (ok) {
        if (!ok) showFeedback("Copie impossible : " + CANONICAL_URL);
      });
    });
  }

def hex_to_rgb(value):
    value = value.lstrip("#")
    return tuple(int(value[i:i + 2], 16) for i in (0, 2, 4))


def _channel(c):
    c = c / 255
    return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4


def relative_luminance(hex_color):
    r, g, b = (_channel(c) for c in hex_to_rgb(hex_color))
    return 0.2126 * r + 0.7152 * g + 0.0722 * b


def contrast_ratio(fg, bg):
    l1, l2 = relative_luminance(fg), relative_luminance(bg)
    hi, lo = max(l1, l2), min(l1, l2)
    return (hi + 0.05) / (lo + 0.05)
