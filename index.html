C'est quoi, la-mise-a-jour.fr ?

Le suivi public de la maintenance du système France. Une équipe a repris le code ; voici son travail.

Chaque affirmation est sourcée ; l'emballage n'engage que l'équipe.

Pourquoi comparer la société à un logiciel ?

Parce qu'un logiciel non maintenu depuis 1958 serait déprécié depuis longtemps.

Aucune version prise en charge. Dernier correctif de sécurité : 1962.

Est-ce que je peux contribuer ?

Oui. Le code source est public : il s'appelle la Constitution.

Pull requests bienvenues. 49.3 non requis.
